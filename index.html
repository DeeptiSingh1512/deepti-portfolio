AI & Vibe Coding

Building with AI

Vibe coding is a development philosophy where you work with AI as a collaborative engineering partner — describing what you want to build in natural language, iterating in real time, and letting the AI handle syntax while you focus on logic, architecture, and user experience.

My flagship vibe-coded project is the Team Task Manager — a production-deployed full-stack app with JWT auth, role-based access, and a live dashboard, built entirely through AI collaboration. I also used AI to build this portfolio.

I use Lovable.dev for rapid UI scaffolding — it generates production-ready React components from plain English prompts — then wire up my own backend logic. Combined with VS Code + GitHub Copilot for in-editor autocomplete, the full vibe coding stack dramatically reduces time from idea to deployed product.

Claude (Anthropic)

Primary AI partner for full-stack architecture, React component design, Express API logic, debugging, and code review. Built Team Task Manager and this portfolio end-to-end.

Lovable.dev

AI-powered UI builder — generate entire React frontends from a text prompt. I use it to scaffold component structure quickly, then connect my own backend and customize logic.

GitHub Copilot

In-editor AI autocomplete in VS Code. Best for boilerplate, function completion, and repetitive code patterns. Pairs perfectly with Claude for larger design decisions.

ChatGPT

Used for rapid concept exploration, library documentation lookups, and understanding unfamiliar patterns like n8n node configs and RTK Query setup.
